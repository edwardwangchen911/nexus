# NEXUS Phase 0–1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the fixture-complete Phase 0 platform and the production-code-complete Phase 1 read-only Fosun integration, including portfolio diagnosis, three-way optimization proposals, Agent research, point-in-time backtesting, forward shadow comparison, and a USD 10,000 internal paper ledger. No broker write route is included.

**Architecture:** Keep the vinext Web console as a same-origin BFF and presentation layer. Put all financial calculations and business state in the Python `nexus-engine` package backed by PostgreSQL and S3-compatible object storage. Run the Fosun adapter as the separate `nexus-fosun-gateway` package with a compile-time read-only operation surface. Cross-service contracts are FastAPI OpenAPI plus HMAC v1; research Agents receive only read-only, redacted tools.

**Tech Stack:** Node.js 22.13+, vinext 1 / React 19 / TypeScript 5 / Vitest / Testing Library / Playwright / axe-core; Python 3.12 / FastAPI / Pydantic 2 / SQLAlchemy 2 / Alembic / PostgreSQL / Polars / PyArrow / DuckDB / exchange-calendars / OpenAI SDK; uv workspace; MinIO for local object storage; Docker Compose.

**Spec:** `docs/superpowers/specs/2026-08-22-nexus-ai-investment-platform-design.md` v4

## Global Constraints

- Phase 0–1 contains no `OrderCreate`, `OrderModify`, `OrderCancel`, `SimAccountCreate`, `SimAccountReset`, subscription CRUD, or Fosun Webhook route. Tests must prove those routes are absent.
- Never use, echo, validate, or store the API key previously pasted in chat. Before real read-only activation, the user must revoke it and provision a rotated key directly in a secret manager.
- `00656.HK` is read-only and receives no fundamental buy/sell conclusion until an HKEX filing provider has a separately approved specification.
- Agent code cannot call the gateway, calculate numeric target weights, write orders, change risk policies, execute arbitrary code, or receive exact account identifiers or total assets.
- Money, prices, quantities, ratios, and API decimals use PostgreSQL `NUMERIC`, Python `Decimal`, and JSON strings. UTC timestamps are timezone-aware; exchange sessions use `America/New_York` and `exchange-calendars`.
- Every task follows red → focused implementation → green → review → commit. Never stage unrelated user files. Do not edit `.openai/hosting.json`.
- Task 1 is the only task run in the current workspace because the starter is untracked. After its baseline commit, run `superpowers:using-git-worktrees` and execute Tasks 2–21 in a `codex/nexus-phase-0-1` worktree.
- A task is not complete until its named focused test and the relevant package-wide checks pass. Checkpoints after Tasks 5, 10, 15, 19, and 21 require the full verification block named there.
