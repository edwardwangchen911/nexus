# 无研究计划的 SEC 基础规则初始化

依据 `docs/design/nexus-durable-sec-monitoring-v1.md`：既有证券的基础发现独立研究 TTL，不强迫模型产生合格计划。本切片修复初始化入口；不改变研究资格、目标表单、预算或历史一次保护。

采用已有 `sec_monitor_rules` 和通知身份账本。新入口只允许当前受保护配置批次且已登记的不可变日限范围中的证券；该范围只限定既有证券，不授予研究权限。CIK 从正常身份原件派生，表单固定 `8-K/8-K/A`。已有正常 SEC 基线可作初始化来源，必须经原强读器验证；该历史基线不代表新规则当前区间完整。当前最新身份也必须正常核验，坏的最新身份不得回退旧身份。

前向迁移只将 `anchor_plan_id` 允许为空，不添加规则字段、不改变旧行 JSON 或审计。空 anchor 必须绑定独立、不可变、同事务有审计的基础来源快照，绑定规则、原范围快照/hash/批次、身份、基线/hash、表单及实际数据库登记时刻。SQL 保留旧非空分支，空分支严格验证来源；缺失、未来、越界、错 hash、无审计均拒绝。来源快照提交时还必须具备对应规则及初始状态，不能孤立登记。存在新事实时禁止降级删除；保留新 schema 兼容维护镜像回滚。

初始化只向前生效，不采集、不调用模型、不生成命中或通知。旧通知占位导入共用现有实现。恢复/暂停/撤销、五分钟节奏、300 秒原件新鲜度、共享稳定键和逐事件消费不变。无现行合格计划仍禁止付费增量。
