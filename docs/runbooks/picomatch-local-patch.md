不登记漏洞风险接受、不关闭 npm audit，也不把原始审计告警改写为零漏洞。

`npm ci` 的正常 postinstall 修补四个安装副本及 Cloudflare/Playwright 的六个内嵌解析器。
补丁检查锁文件、完整原始文件哈希及安装包其余入口文件；先检查全部目标，再写入。
重复执行不改变已修复内容；未知上游版本、缺失补丁或内容漂移均拒绝。

原解析器会将单分支中的无界量词再次重复。补丁复用原有“按字面量匹配”的安全回退，
保留已有安全字符类展平、没有前缀重叠的纯文字分支、严格的单个正字符类和单个转义字符。
忽略大小写时，多分支重复也回退；`nobracket`、`unescape` 不得使上述有限语法重新产生嵌套量词。
其他复杂重复 extglob 可能因此按字面量匹配。这是明确的保守兼容边界；普通 glob、文件后缀、
非重复 extglob、路径和数组匹配保持现有行为。没有承诺支持任意原始正则表达式或消除所有正则风险。
