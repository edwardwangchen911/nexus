# NEXUS 组合管理产品合同 v0.1

## 一、产品对象

**长期方向：目标组合驱动的有界自主管理。当前第一切片：多候选组合级目标进入现有内部模拟链路。**

| 对象 | 合同定义 |
|---|---|
| **模型组合** | 单一、独立的内部模拟投资组合。优先绑定并复用已有兼容模拟账户，不预设新建账户管理系统，不自动清空、重置或覆盖历史。 |
| **投资政策** | 用户批准的投资目标、可投资范围、配置规则、风险边界和运行授权。Agent 不得自行修改。 |
| **目标组合** | 根据投资判断与确定性配置规则形成、持续生效的期望持仓和现金配置。采用不可变版本，不是一次性买卖信号。 |
| **实际组合** | 由内部模拟实际成交形成的持仓、现金及预留状态。目标和未成交订单不得冒充实际持仓。 |
| **调整计划** | 为实现某一目标版本而安排的组合调整，明确对应目标、调整范围、资源占用和执行结果。计划不等于成交。 |

模型组合保留三类职责：**核心仓承载持续性投资观点，战术仓承载有明确机会窗口的观点，现金仓承担资金缓冲及等待更合适机会的职责。**具体比例、周期和标准仓位均为待确认政策参数。

真实账户继续只读；作为研究背景或对照须由用户明确选择，不自动复制持仓。`00656.HK` 仅作只读展示，`execution_locked=true` 始终保持。本合同不授予外部写入或实盘权限。

## 二、必要业务语义

### 1. 股票池批准的是政策，不是每份成员快照

用户批准证券类型、可投资范围和筛选边界。系统可以依据已批准政策自动生成可追溯的成员快照，无须用户逐份审批。

扩大证券类型或改变已批准边界，必须重新确认。观察列表只影响研究优先级，不赋予交易资格；Agent 不得借机会发现自行扩大可投资范围。

### 2. 未重新研究的持仓继承现有目标

本轮研究范围不等于全部持仓。未触发重新研究的持仓，由确定性代码继承现有生效目标，不要求 Agent 每轮重新研究或补写维持理由。

继承目标不等于更新研究有效期，也不免除执行前校验。新候选不得导致未变更持仓被隐式重新分配或重新归一化。

### 3. 维持的是持续目标，不是重复买入信号

相同投资判断继续有效时，延续已有目标，不把“仍然看好”解释为再次增加固定仓位。

实际组合因价格变化、部分成交等原因偏离目标时，是否调整由适用政策决定，不由研究次数或运行次数决定。已成交部分和未结订单必须纳入差额判断，避免重复交易。

### 4. 遗漏不等于退出，现金是合法选择

未出现在本轮候选、研究清单或新成员快照中的持仓，仍须被管理。退出必须来自明确投资意图或已生效的风险政策，不能由名单遗漏隐式触发。

可以因机会不足、政策约束或等待条件而保留现金，不要求填满仓位。主动选择现金、研究不足、风控拒绝和执行受阻必须分别说明。

### 5. 目标版本不可原地修改

**目标组合采用不可变版本。同一模型组合同一时刻最多只有一个生效目标。**

每次合法变更产生新目标版本，并引用被替代的上一版本、适用政策版本、投资判断和证据时点。首次建立目标时，明确不存在上一版本。

历史目标不得回写或删除。后续研究、行情、政策和执行结果，不得反向修改历史目标及其决策依据。

新提案不等于新目标生效。目标替代必须满足业务准入、适用政策和调整计划占用约束。每个调整计划及其订单必须关联所依据的目标版本；历史订单和成交不得因目标更新而重新归属最新版本。

### 6. 同时最多一个占用资金或持仓的调整计划

**同一模型组合同一时刻最多只有一个占用资金或持仓的调整计划。**

研究可以继续，也可以形成新提案；但上一计划仍处于执行中、部分完成或结果未知时，新提案不得重复承诺同一现金或持仓，也不得直接替换生效目标，须先完成对账。

对账完成是必要条件，但不等于占用已经解除。只要仍有未结订单、未释放预留或未查明结果，就不能视为已经腾出资源。

旧计划完成或确认取消、相关占用结清或释放、订单与实际组合核对一致且不存在未知结果后，新提案方可按届时实际状态和适用证据重新校验，不得直接执行等待期间形成的过期配置。

该约束不阻止既有计划的风控、取消、对账和收尾处理，但不得借此另起并行占用计划。

### 7. 提案、目标和实际结果分别成立

提案未通过校验时，不替代生效目标；目标更新不撤销历史成交，也不自动取消未结订单。

风控缩减、部分成交和执行失败必须保留各自原因，不得通过修改生效目标，把未达成的结果包装成原本意图。需要改变目标时，仍须遵守不可变版本和计划占用约束。

## 三、Agent 输出

Agent 输出**本轮投资取舍及目标变更意图**，不输出配置金额、目标权重或订单数量。

| 输出内容 | 必要含义 |
|---|---|
| **判断范围** | 哪些新候选及已有持仓接受了本轮研究，哪些不在本轮变更范围内。 |
| **投资动作语义** | 拟纳入、维持已有目标、增加或降低配置意图、明确退出、暂缓。配置程度的表达方式由适用政策限定。 |
| **组合级取舍** | 为什么选择 A 而非 B、为什么以 A 替换 C、为什么保留现金；说明必要的优先顺序、替换前提和依赖。 |
| **仓位职责与有效性** | 核心或战术职责、持有理由、期限依据、失效条件和复核触发理由，具体期限受政策约束。 |
| **证据与限制** | 支持证据、关键反方证据、未解决问题，以及它们影响哪些判断。 |

未研究持仓的目标继承由确定性代码完成，不要求 Agent 逐项生成“维持”意见。相对优先级不是胜率，也不授予风控豁免。

## 四、确定性代码输出

| 输出内容 | 必要含义 |
|---|---|
| **准入结论** | 候选是否满足股票池政策、证券身份、必要证据、时效及其他适用条件；不合格时说明原因。 |
| **完整目标及版本依据** | 合并继承目标与合法变更，计算资金配置、目标权重和现金；明确继承项、变化项、未获配置项，以及上一目标、政策、判断和证据时点。 |
| **目标生效结论** | 区分形成提案、允许生效和已经生效；明确是否因旧计划占用、未结订单或结果未知而受阻。 |
| **风险处理结果** | 哪些调整获准、被缩减或被拒绝及对应约束；不得将风控结果改写为 Agent 原始判断。 |
| **可执行差额与计划归属** | 根据目标、实际持仓、可用资源和未结订单计算尚未被覆盖的调整数量；明确计划和订单所对应的目标版本。 |
| **执行与结果事实** | 复用既有订单、成交、账本和绩效能力，给出已完成部分、剩余订单、资源占用、未知事项及目标偏差。 |

未成交卖出所得不得提前视为可用资金。无法满足约束时，不得擅自改变政策、扩大股票池或调整未授权的其他目标。

**必要配置规则未明确时，输出“政策未确认”，不自行补默认值。**

## 五、必要状态

以下是必须能够区分的业务含义，优先沿用已有状态，不预设新建独立状态体系。

| 维度 | 必须区分 |
|---|---|
| **目标** | 尚未建立、生效、被新版本替代。生效与替代关系可追溯，目标内容不可回写。 |
| **本轮判断** | 提议变更、维持原目标、主动保留现金、证据不足、政策未确认。 |
| **准入与风控** | 通过、缩减、拒绝、输入不足。 |
| **计划与执行** | 无须交易、等待前序计划结清、等待执行条件、执行中、部分完成、已完成、确认取消、受阻、结果未知。 |
| **资源占用** | 已明确占用、已结清或释放、尚未查明。依据订单、预留和对账事实判定。 |

目标状态与计划状态分别表达：旧目标可以继续生效，同时存在等待处理的新提案；旧计划部分完成，不代表新目标已经接管。

“已停止运行”“取消请求已发送”或“对账流程结束”，均不能单独证明资源已释放。

研究复核到期、提案过期和投资观点失效也必须区分：研究到期不自动清仓，提案过期不抹除已成交部分，没有订单不统一显示为主动观望。

## 六、第一切片输入与输出

**切片目标：将多候选的组合级取舍转换为持续有效的目标，并接入现有模拟链路，同时保证目标可追溯、计划不并行占用资源。**

### 输入

| 输入 | 边界 |
|---|---|
| **已有内部模拟账户及实际状态** | 核验账户适用性、现金、持仓、预留、未结订单及历史记录；不复制真实账户，不预设新建或重置账户。 |
| **已有生效目标及调整计划状态** | 作为继承和变更基线；核对是否存在执行中、部分完成或结果未知的计划。尚无目标时须明确初始目标来源，不能自动把实际持仓当作目标。 |
| **股票池政策与成员快照** | 政策已经批准；成员快照依据该政策生成并通过校验，无须逐份人工批准。 |
| **有界的多候选研究结果** | 包含新候选及本轮明确需要调整的持仓，可由现有研究入口提供，不以完整自动发现漏斗为前提。 |
| **适用政策与执行证据** | 本切片实际需要的配置规则、硬风控、运行授权及行情用途条件已经明确并可核验。 |

### 输出

形成一份**完整目标提案及变更说明**，明确继承、纳入、调整、退出和现金选择。

满足准入和计划占用约束时，以不可变新版本替代上一生效目标；否则保留原目标，给出等待、拒绝或政策未确认的原因。无目标变化时继续使用原生效版本，不因重复运行制造无意义变更。

需要交易时，形成明确归属该目标版本的调整计划，进入既有模拟订单、成交、账本和绩效链路；通过现有读取能力核对同一决策的结果、资源占用及目标偏差。

第一切片不以三仓完整展示、政策配置体验、自动研究排队或事件调度完成为前提。三仓职责可随投资意图保留，但不扩建三套独立策略。

## 七、第一切片验收场景

| 场景 | 可观察的验收结果 |
|---|---|
| **复用已有账户** | 历史记录未被覆盖，未自动重置本金或复制真实持仓，执行锁保持不变。 |
| **多个合格候选竞争资金** | 能表达选择与暂缓理由，由确定性规则配置资金，不再限定为单一固定标的。 |
| **部分持仓未重新研究** | 继承原生效目标，不被清仓或隐式重新分配，不触发强制全量研究。 |
| **相同判断重复运行** | 不累加目标，不重复创建已被成交或未结订单覆盖的交易需求。 |
| **目标发生合法变更** | 产生新版本，引用上一目标、适用政策、投资判断和证据时点；同一时刻最多一个生效目标。 |
| **后续证据或政策更新** | 历史目标内容不变；历史计划、订单和成交仍可还原当时依据及原目标归属。 |
| **没有合适机会，或资金和风险约束不足** | 可以保留现金、维持原目标、缩减或拒绝调整；原因明确，不强迫交易、不放宽限制。 |
| **旧计划未结束时出现新提案** | 研究和提案可以保留，但不得直接替换生效目标或启动新的资源占用计划。 |
| **A 替换 C，仅部分完成** | 不提前使用未成交卖出所得；明确已成交部分、剩余现金和未完成目标，不宣称替换完成。 |
| **结果未知、取消尚未确认，或对账后仍有未结订单与预留** | 保持相应占用和目标切换阻断，不因超时、取消请求或对账动作已完成而放行。 |
| **旧计划结束且占用结清** | 新提案按最新实际状态和适用证据重新校验，通过后才能启用新目标及调整计划。 |
| **自然产生可执行建仓意图** | 可核对研究、目标版本、计划、风控、订单、成交、现金、持仓和绩效；目标与实际差异有解释。 |

受控场景用于验证成交、部分完成和拒绝等分支；自然运行用于证明真实证据驱动的业务链路。**只有不交易结果，不算自然建仓验收完成；不得为验收强迫买入。**

## 九、尚待用户决定的政策参数

**此前方案中的所有具体比例、持有周期、复核周期和标准仓位，均为待确认政策参数，不视为已批准默认值。**

| 参数组 | 待确认事项 |
|---|---|
| **组合起点与目标** | 复用账户及起始状态、模拟本金、初始目标来源、投资目标、整体期限和风险水平。 |
| **股票池政策** | 允许证券类型、范围与筛选边界、成员更新规则、移出池后的持仓处置要求。 |
| **资金配置** | 核心／战术／现金的参考比例与上下限、例外条件、标准仓位、配置档位及优先级到资金分配的规则。 |
| **调仓与风险** | 目标偏离容忍、最小调整要求、换手限制、现金及集中度限制、风险触发后的处理与恢复条件。 |
| **期限与复核** | 各类持有周期、定期复核周期、事件触发条件、研究有效期、提案有效期及战术期限结束后的处置。 |
| **运行与评价** | 运行频率、研究预算、观察列表优先级、暂停及未结订单处理、成本假设、比较基准和评价窗口。 |

本合同不覆盖或放宽既有已核验的生效硬风控。第一切片只需确认其实际使用的政策参数，其余随对应切片确认，不提前扩建完整政策系统。

**目标版本不可变、同一时刻最多一个生效目标、最多一个资源占用中的调整计划，是本合同的固定约束，不属于可由 Agent 调整的政策参数。**
