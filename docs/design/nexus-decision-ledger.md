# NEXUS Decision Ledger

NEXUS 的视觉语言不是交易大屏，也不是通用 SaaS 后台。它是一套面向单一投资者的决策账簿：高密度但克制，强调事实来源、决策资格和人工审批边界。

## 设计原则

1. **权威先于装饰**：页面先说明数据来自哪里、能否展示、能否参与决策，再展示组合与研究结果。
2. **状态原文可见**：`DISPLAY_READY`、`DECISION_READY`、`RECONCILIATION_REQUIRED` 等契约值不得被只用颜色或模糊文案替代。
3. **Agent 是研究层**：Agent 可以组织证据和提出方案；确定性代码负责门禁、风控和审批，执行始终显示人工锁。
4. **密度来自结构**：通过稳定的数字列、分组、细分隔线和层级获得专业感，不通过堆叠卡片、发光边框或行情装饰制造“金融感”。
5. **未知就是未知**：缺失、过期和冲突必须显式呈现，不使用演示数据填补页面。

## 视觉系统

- 基底：深海军蓝画布、低反射表面、冷白正文。
- 信号色：蓝色表示当前路径，薄荷绿表示已验证，金色表示需关注，珊瑚红表示阻断或风险。
- 字体：界面使用 Geist；状态码、ID、时间与数值使用 Geist Mono。保留系统中文字体回退，避免联网字体依赖。
- 形状：小圆角、细分隔线、极少阴影。品牌标记与 Authority Circuit 是主要识别元素。
- 动效：仅用于状态反馈与导航，不自动播放行情或制造紧迫感；尊重 `prefers-reduced-motion`。

## 可复用组件

- `IntelligenceHeader`：统一页面任务、运行模式、状态与主动作。
- `AuthorityLedger`：固定表达 Provider fact → Display gate → Decision gate → Human approval。
- 既有 `PortfolioValuationSummary`、图表和状态组件继续复用；不引入新的组件库或默认主题。

## 禁止模式

- 白底圆角卡片墙、渐变紫色英雄区、霓虹加密货币风格。
- 用 AI 评分替代确定性门禁，或在界面暗示 Agent 可以直接下单。
- 为了视觉丰满而伪造持仓、收益、报价或建议。
